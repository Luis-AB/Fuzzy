# CLPSO-FUZZY

CLPSO-FUZZY is a MATLAB implementation of Comprehensive Learning Particle Swarm Optimization (CLPSO) with a Mamdani fuzzy controller. At each iteration, the controller adjusts the inertia weight (ω) and the cognitive coefficient (c₁). CLPSO selects an exemplar for each dimension, and c₁ scales how strongly the particle moves toward those exemplars.
