# PSOGSA-FUZZY

PSOGSA-FUZZY is a MATLAB implementation of PSOGSA, a hybrid of Particle Swarm Optimization (PSO) and the Gravitational Search Algorithm (GSA), with a Mamdani fuzzy controller. At each iteration, the controller adjusts the inertia weight (ω) and the cognitive coefficient (c₁) based on swarm stagnation and diversity
